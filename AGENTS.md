# Portfolio Project Instructions

## Website
This is Srikar Mattegunta's personal portfolio.

Pages:
- index.html: introduction and navigation
- about.html: background, education, experience, and interests
- projects.html: three projects with screenshots
- skills.html: programming, leadership, and communication skills
- contact.html: email contact information

## Design
- Dark charcoal background: #0e1117; raised surfaces: #151b25
- Off-white headings: #eef2f9; secondary text: #aab5c7
- Cool blue accents: #91b4ff, with dark text on filled blue buttons
- Engineering-inspired layout, fine borders, restrained corners, and generous spacing
- Arial/Helvetica body and headings, monospace labels, and a Georgia italic accent
- Homepage uses a decorative inline SVG engineering diagram, not a project claim
- Larger project showcases retain two side-by-side screenshots with image enlargement
- Responsive phone/laptop layouts, shared footer, and a keyboard skip link on every page

## Code Rules
- Use plain HTML, CSS, and JavaScript. No frameworks.
- Use relative paths for local links, images, styles, and scripts.
- Keep shared styles in styles.css and JavaScript in script.js.
- Use semantic HTML and one h1 per page.
- Give images meaningful alt text.
- Keep every image under 500 KB.
- Keep navigation and image popups usable with a keyboard.
- Do not invent personal information, achievements, or project features.

## Working Together
- Teach one manageable step at a time.
- Explain what each change does.
- When asked to implement a change, keep it within the requested scope.
- Check existing files before making changes.

## Git
After each completed and reviewed task:
- Commit the relevant changes with a clear message.
- Push the commit to GitHub.
